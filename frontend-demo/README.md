# AKIRA Wrist Component — Frontend Demo

This is the interactive frontend dashboard for the AKIRA Smart Post-Operative Rehabilitation System. It was designed specifically for supervisor demonstrations, connecting directly to the local offline CSV outputs generated by the Python preprocessing and autoencoder pipelines.

## 🛠 Features Implemented
- **Dashboard Overview:** Displays actual analyzed samples and dynamically calculated anomalies.
- **IMU Data Explorer:** Plots interactive accelerometer and gyroscope time-series from the standardized WatchHand set.
- **Movement Analysis:** Extracts duration and acceleration/gyroscope magnitude features for trials.
- **AI Anomaly Detection:** Scatter plot mapping the exact Autoencoder Mean Squared Error (MSE) against the 95th-percentile threshold.
- **System Status:** Details the specific limitations of the single-IMU prototype vs the planned dual-IMU clinical system.

*Note: The **Session History** and **Range of Motion (ROM)** views currently render as styled placeholders, as the public dataset lacks longitudinal tracking and true synchronized 3D orientation kinematics.*

## 🚀 How to Run the Dashboard

### 1. Open the project folder
Ensure you have a terminal (PowerShell or VS Code Terminal) open in the project root:
```powershell
cd C:\Users\ROG STRIX\Desktop\Wrist_Component\frontend-demo
```

### 2. Install dependencies (First time only)
```powershell
npm install
```

### 3. Start the Development Server
```powershell
npm run dev
```
Once it starts, hold `Ctrl` and click the URL printed in the terminal (e.g., `http://localhost:5173`) to view the application in your browser.

To stop the server, click inside the terminal and press `Ctrl+C`.

### 4. Build for Production
If you need to compile the static HTML/JS/CSS assets:
```powershell
npm run build
```
The optimized files will be output to the `frontend-demo/dist/` directory.

## 📁 Data Integration

To ensure the presentation runs instantly without requiring the Python `FastAPI` backend or physical hardware to be active concurrently, the dashboard securely reads from `src/data/demo_data.json`. 

This JSON file is not fabricated. It was explicitly generated from a snapshot of your genuine CSV results:
- `02_STANDARDIZED_DATA/WatchHand_standard.csv`
- `06_FEATURES/wrist_features.csv`
- `08_RESULTS/predictions_demo.csv`

No live hardware connection is maintained during this offline demonstration.

## 🐛 Common Errors

- **`'npm' is not recognized`**: You need to install Node.js (https://nodejs.org).
- **Blank page or CSS missing**: Ensure you are running `npm run dev` from *inside* the `frontend-demo` folder, not the parent `Wrist_Component` folder.
- **Chart is completely blank**: Some sample trials in the public dataset might have empty chunks. Switch the data subset or verify the JSON snapshot.
