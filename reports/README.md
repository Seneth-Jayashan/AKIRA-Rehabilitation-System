# Research Documentation Structure

Welcome to the AKIRA research documentation directory. The documentation has been explicitly reorganized to trace the linear pipeline of the research workflow.

Recommended Supervisor Review Order:

1. **01_DATA_AUDIT**
   → Dataset inspection, quality checks, subject split, preprocessing and anomaly handling.
2. **02_MODEL_DEVELOPMENT**
   → Model architecture, baseline comparison and ablation experiments.
3. **03_FINAL_EVALUATION**
   → Final subject-independent test results and rehabilitation-related metric validation.
4. **04_FINAL_PACKAGING**
   → Final research documentation, reproducibility information, limitations and deployment specification.
5. **05_VISUAL_RESULTS**
   → Figures and visual evidence used for thesis, presentation and viva.
