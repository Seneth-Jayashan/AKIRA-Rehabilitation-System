# 05 Visual Results

## 1. Purpose of the Folder
This directory acts as the central repository for all generated plots, charts, and diagrams utilized across the documentation and the final presentation.

## 2. What Files are Inside
- **architecture/**: Diagrams of the TCN network topology.
- **pipeline/**: High-level research and preprocessing pipeline flowcharts.
- **model_comparison/**: (If applicable) Visual comparisons of baseline architectures.
- **final_evaluation/**: Confusion matrices, error-vs-angle distributions, and kinematic trajectory plots.
- **rehabilitation_metrics/**: Visualizations tying performance to clinical metrics.

## 3. Why Those Files Matter
They provide the necessary visual evidence to rapidly comprehend complex temporal data, error distributions, and network topographies.

## 4. Workflow Context
This is **Stage 5**, aggregating visual outputs generated throughout all previous stages.

## 5. What a Supervisor Should Look at First
The `final_evaluation/` subdirectory, specifically the trajectory plots (`traj_best.png`, `traj_worst.png`), provides an immediate intuitive understanding of how the model physically performs over time.
