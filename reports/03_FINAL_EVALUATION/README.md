# 03 Final Evaluation

## 1. Purpose of the Folder
This directory houses the ultimate, locked test-set results and the translation of raw model metrics into domain-relevant rehabilitation measures.

## 2. What Files are Inside
- **final_test/**: The comprehensive test reports, smoke tests, and error analysis conducted on the strictly held-out subjects.
- **rehabilitation_metrics/**: Validation showing how the raw MAE/RMSE translates into clinically relevant measurements (e.g., ROM accuracy).
- **final_results_master.csv**: The authoritative, centralized comma-separated ledger of all final performance metrics across all models.

## 3. Why Those Files Matter
This is the core scientific contribution of the project. These files represent the untampered, definitive predictive capability of the final AKIRA prototype on unseen patients.

## 4. Workflow Context
This represents **Stage 3** of the research pipeline. It is the culmination of the data audit and model tuning phases.

## 5. What a Supervisor Should Look at First
Examine `final_test/final_test_report.md` immediately, followed by `final_results_master.csv` for the precise quantitative records.
